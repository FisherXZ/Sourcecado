# Monid component evidence

Production React components and Warm Operator styles use synthetic Maya/Acme
data. The browser intercepted every API request. No credential, account or
paid provider call was used. **Not connected** is the real installation claim;
the research images demonstrate fake cases.

| State | 1440px | 390px |
|---|---|---|
| Personal-key setup, honestly not connected | [Wide](not-connected-1440.png) | [Narrow](not-connected-390.png) |
| Exact input, quote, maximum and once-only decision | [Wide](once-review-1440.png) | [Narrow](once-review-390.png) |
| Untrusted source, actual charge unavailable | [Wide](result-1440.png) | [Narrow](result-390.png) |
| Unknown outcome held for review | [Wide](unknown-1440.png) | [Narrow](unknown-390.png) |

Checks covered password masking, keyboard activation, focus moving into the
query/review/result, no Always allow control and no horizontal overflow at
390px. Narrow controls have a 44px minimum height and information is at least
13px. The exact request is visible because it is part of the paid decision;
raw result data sits behind an inspection disclosure.

These component fixtures do not prove a connected account, native-shell
acceptance, live data quality, vendor billing or a real sourcing run. The
[connector guide](../../engineering/monid-sources.md) records current limits.
