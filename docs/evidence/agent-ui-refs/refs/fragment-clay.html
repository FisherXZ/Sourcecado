Clay: common patterns

All images are Clay marketing, changelog and blog renders of the real app UI, not raw screenshots. Sizes below are ratios read from the images. Map them to our 13-14px body.

  • Light canvas, white surfaces, 1px light borders, almost no shadow inside the app. Cards sit near 8-10px radius, buttons near 6px. This fits Warm Operator with no change.
  • Every row, chip and button starts with an icon: column type icons, provider logos on waterfall steps, check and X on Accept and Discard. Status is a leading glyph (spinner, then green check circle), not a sentence.
  • Credits are a coin-icon pill next to the action it prices: "1 / row", "~2K total", "5.4 / row". They never appear as a paragraph.
  • Provider identity is the trust signal. Each waterfall step and each enriched field carries the provider logo.
  • The placeholder does the labelling in the composer: "What do you want to do with Clay?". It changes to "Ask questions and add enrichments" once a thread exists.
  • One filled primary button per surface (Accept, Save, Import and run, Edit). All other buttons are outlined with an icon.

Do not copy: mid-gray secondary text (field labels, subtitles, empty-state text, "Not found" cells) and 11-12px chips break our 13px and no-muted rules. Config panels put labels above inputs ("Model", "Use Case", "Clay Credit Budget"). The Slack Approve and Deny buttons have no icons. The accent is blue, ours is avocado. Tilted and 3D frames in the changelog art are decoration, so copy only the UI inside.

1. Sidebar / workspace rail

Clay

App shell from the Signals page: icon-only destination column, labeled panel with scope switcher and collapse, link list, audiences list with search and plus.

Source: clay.com/signals

Clay

Audiences app: section header row "All audiences" with search and plus icons, then Created by me and Workspace groups.

Source: clay.com/audiences

Steal this:

  • Two tiers. First, an icon-only column with 12 destinations and one tinted active square. Second, a labeled panel (about 5x wider) whose top row is the scope switcher ("Companies" with a chevron) and a panel-collapse icon on the right of the same row.
  • Destination link: 16px icon, label, row height about 2.4x text size, 8px gap. Active row is a tinted fill with accent icon and text. No borders.
  • Create lives in the section header, not a big button: "All audiences" with chevron, then a search icon and a "+" icon, right aligned.
  • Recent items are grouped under "Created by me" and "Workspace". Each item has a doc icon and a kebab on the right. The list fades out and ends with an "N more" row.
  • No account footer is shown in any Clay image.

Do not copy: group labels and item text in the lower half are pale gray, and the icon column has no labels. Use full-ink labels and tooltips with names.

Borrow: rail (Signals page) for the whole structure. Take rail-2 for the section-header row with search and plus.

  • Input box: placeholder is a question, 2 rows tall, 10px radius. Bottom row: "+" outlined square button (context) at the left, send arrow square button at the right. Send is disabled until text exists.

6. Agent step rows

Clay

Claygent step list: check circle for done, spinner for running, blank for pending; per-row streaming phase text in the table.

Source: clay.com/claygent

Clay

Clay agent step card: actor icon and name, three rows with right-aligned check or spinner, dotted link to the next action.

Source: clay.com/

Steal this:

  • Step list card: title, then rows of about 2.4x text height with a 1px divider. Done = filled green check circle. Running = spinner glyph. Pending = blank slot. Same position in every row.
  • Phase text while a row runs: "Extracting data...", "Synthesizing insights...", "Structuring results...". Three fixed verbs, in order.
  • Grouping (toolstep-2): a card per actor with an icon tile, name and subtitle, then rows with the status icon right aligned. A dotted line links to the next action card.
  • Inputs get their own card before the steps ("Per-row data inputs"), with the same check and spinner glyphs.
  • Not shown: argument summaries, expand chevrons, timing. Add them ourselves: verb, object, then the argument in ink.

Do not copy: rows are bare labels with no argument and no duration. Muted phase text is gray in the table cells.

Borrow: toolstep for the status glyph rules and the phase verbs. Take toolstep-2 for grouping steps under one actor.

Gap list

  • 5. Reasoning / thinking disclosure: no official Clay image. "Claygent Replay" is only named in the Navigator changelog text.
  • 11. Failed step with retry, fix connection or skip: only empty-result cell states exist.
  • 12. Hover icon actions on messages (copy, rerun, edit): none. Only row context menus.
  • 9. Resolved approval state: none. Only the pending prompt.
  • 4. Keyboard hints and a model or tool picker inside the chat composer: none.
  • Video-only demos (Claygent look-up, Sequencer product demo, MCP flows) were not used because the brief says images only. Frame grabs from clay.com/claygent and clay.com/sequencer could fill the thinking and step gaps if approved.
