Attio: common patterns

  • Every control has an icon: nav rows, tabs, chips, and action buttons all carry a 16px line icon before the label. Icon-only buttons are the default for secondary actions.
  • One chip style does four jobs: context, agent steps, sources, and suggestions. 1px border, 8px radius or pill, 28 to 32px tall, icon + label + optional count.
  • The placeholder does the work. "Ask anything…" and "Search…" sit inside the field, with no label above it.
  • Quiet density: 13 to 14px text, one-line rows around 32px, selected state is a neutral fill. Accent blue appears only on the primary button and the focus ring.
  • Structure comes from 1px borders. Soft shadow appears only on floating layers: menus, popovers, and the record peek.
  • Dark mode keeps the same layout and spacing. Surfaces move one step per level and borders get lighter (see the dark thread, model picker, and rail images).
  • Agent work shows as past-tense verb chips, not prose.

Do not copy: assistant narration before a tool call ("Let me get the call details first"); muted gray captions that carry real information (credits line, "Confidence level" labels, "Draft email" caption); text-only buttons (Deny, Always allow, Allow once, Discard, Auto); labels above fields in settings; random hue icon tiles; blue as the accent (ours is avocado #5B8C2A).
